## Method

每篇精读走同一条流水线：

1. **读 README 和 issue 区** — 搞清楚它解决什么问题、设计哲学是什么
2. **跑通 quickstart** — 跑不起来的项目不值得精读
3. **挑一个核心模块画调用链路** — 从入口到出口，搞清楚数据怎么流
4. **写成笔记** — 用自己的话复述，能讲清楚才算读懂
