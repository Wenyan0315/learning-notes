## 第 7 周①②③ · CNN 基础与经典网络【重建版】

### ① 卷积与池化：图像的归纳偏置

**速览**：卷积把"局部性 + 平移不变性"焊进结构——局部连接 + 权重共享，参数量从 H·W·Cin·Cout 降到 k·k·Cin·Cout。

$$H_{out} = \left\lfloor \frac{H + 2P - K}{S} \right\rfloor + 1 \quad (P=padding,\ K=kernel,\ S=stride)$$

**关键要点**：感受野随层数与 stride 累积增长；3×3 堆叠优于大核；池化降分辨率扩感受野但丢位置信息；浅层通道响应边缘、深层响应语义。

#### 深入：卷积的数学定义与"互相关"工程实现

数学卷积定义含核翻转：(f∗g)(i,j) = ΣₘΣₙ f(i−m, j−n)g(m,n)。**DL 框架实现的全部是"互相关"（不翻转）**——因为卷积核是学出来的，翻不翻转不影响表达能力，只影响符号约定。面试问"卷积神经网络里的卷积是严格的数学卷积吗"，答案：不是，是互相关。

**输出尺寸公式推广（带空洞率 d）**：等效核 K' = K + (K−1)(d−1)，H_out = ⌊(H + 2P − K')/S⌋ + 1 + 1 的部分不变。空洞卷积（dilated）不增加参数就扩大感受野，是分割网络（DeepLab）的核心件。

#### 深入：感受野的递推公式（高频计算题）

设第 l 层的核 k_l、步长 s_l，第 l 层输出单元的感受野 r_l（相对输入图像的边长）：

$$r_0 = 1, \qquad r_l = r_{l-1} + (k_l - 1)\prod_{i=1}^{l-1} s_i$$

**验证例**（VGG 风格，全 3×3、stride=1，每两层后一个 stride=2 池化）：

| 层 | k | s | r |
|---|---|---|---|
| conv1_1 | 3 | 1 | 1+2=3 |
| conv1_2 | 3 | 1 | 3+2=5 |
| pool1 | 2 | 2 | 5 |
| conv2_1 | 3 | 1 | 5+2·2=9 |
| conv2_2 | 3 | 1 | 9+4=13 |

两组 3×3（感受野 5）之后接 stride 2，感受野跳步加倍——这就是"小核堆叠 + 下采样"的累积效应。两个 3×3 = 5×5 的感受野，三个 3×3 = 7×7，参数 27 vs 49/81，且多两次非线性——**VGG 洞察的严格版本**。

**每个输出位置看到原图多大区域之外，别忘了"有效感受野"**（Effective Receptive Field）：实际梯度贡献呈高斯衰减，中心强边缘弱——理论上 13×13 的区域，真正起决定作用的可能是中心 5×5。这解释了为什么小目标检测难：浅层小目标经过下采样后落入弱响应区。

#### 深入：池化与现代替代

max pooling：取窗口最大值——保留最强响应、抗小位移；average pooling：平滑、保留能量信息。代价是**不可逆的降采样 + 位置信息丢失**（分割任务的天敌）。

现代替代：stride=2 的卷积直接下采样（可学习、信息损失小）；**抗混叠下采样**（BlurPool，下采样前先低通滤波）——违反奈奎斯特采样定理（先下采样后高频混杂）是传统 stride 卷积的隐伤，BlurPool 以几乎零成本涨点。

#### 深入：分组卷积 → 深度可分离（第 38 天的铺垫）

普通卷积：每个输出通道连接**全部**输入通道。分组卷积（grouped）把通道分 g 组，各组独立卷积——参数量 ÷g，组间无信息流通。g = Cin（每组一个通道）即 depthwise 卷积；depthwise + 1×1 pointwise = 深度可分离卷积（第 38 天详解）。

#### 工程场景（扩展）

内容审核图像链路 = CNN 特征提取 + 规则后处理（置信度阈值、黑名单兜底、多帧投票）。扩展一个关键设计：**多帧投票**的本质是"时间维的集成"，把单帧误检（瞬时遮挡、压缩块）通过多数表决压掉——结构上的池化与系统级的投票是同一种"局部不变性"思维。

### ② 从 LeNet 到 VGG：深度军备竞赛

**速览**：CNN 演进主线 = 瓶颈驱动。LeNet（卷积+池化奠基）→ AlexNet（ReLU+GPU+Dropout+数据增强）→ VGG（统一 3×3 积木）。

| 网络 | 年份 | 解决的瓶颈 | 关键创新 |
|---|---|---|---|
| LeNet-5 | 1998 | 手写数字识别 | 卷积+池化奠基，端到端训练 |
| AlexNet | 2012 | 深度网络训不动 | ReLU、GPU、Dropout、数据增强；top-5 15.3% |
| VGG | 2014 | 结构设计混乱 | 只用 3×3 + 2×2 池化，证明深度是硬通货（16/19 层） |

**深入——AlexNet 的三个常被忽略的细节**：①双 GPU 训练（当时单卡 3GB 显存放不下）——架构设计被硬件倒逼；②**LRN（局部响应归一化）**——被后来的 BN 完全取代，读老代码会遇到；③重叠池化（stride < kernel）——细微涨点。

**深入——VGG 的教训比优点同样重要**：138M 参数大头在三个全连接层（约 120M）。全连接层 = 特征图位置 × 通道的稠密矩阵，对输入尺寸敏感、参数冗余。解法即 GAP（全局平均池化）：每个通道输出一个均值 → 7×7×512 → 512 向量直接进分类器，参数骤降且附带平移鲁棒。**"分类头轻量化"从此成为惯例。**

### ③ 1×1 卷积与 Inception：便宜的通道运算

**速览**：1×1 卷积 = 跨通道线性组合，升/降维、增非线性；Inception 多分支并行 + 各贵分支前 1×1 降维——"先压缩再加工"。

**深入——1×1 卷积与 MLP 的同构**：对特征图每个空间位置，1×1 卷积 = 一个作用于"通道维"的共享 MLP：输入 Cin 维 → 隐层（带激活，多层 1×1 时）→ 输出 Cout 维。理解这一点，就理解了为什么 1×1 后必须接非线性才有意义（纯一层 1×1 仍是线性变换），也理解了 SE 模块（通道注意力，先 GAP 压缩成向量再过小 MLP）本质是两个 1×1。

**深入——Inception 系列演进（v1→v4）**：

- **Inception v1（GoogLeNet, 2014）**：1×1/3×3/5×5/池化四分支并行 + 分支前 1×1 降维；22 层；辅助分类器（中间层引分支接小分类头，防梯度消失——残差连接普及前的过渡方案）；
- **v3（2015）**：5×5 拆成两个 3×3、n×n 拆成 1×n + n×1（非对称分解）——进一步省参数；
- **v4 / Inception-ResNet（2016）**：与残差思想合流——多分支结构最终被更简洁的残差统一。

**工程视角**：Inception 的多分支 = 算子碎片化，推理框架上难以融合优化，硬件利用率低。**理论 FLOPs 友好 ≠ 硬件友好**——这个教训在深度可分离卷积上以"内存访问成本"的形式再次出现（第 38 天要点 1）。

## 第 7 周④（第 37 天）· ResNet 与深度网络的退化问题【推送原文】

### 核心概念

**一句话**：网络加深后**训练误差**反而上升——这不是过拟合（过拟合应训练低测试更低），也不是梯度消失（BN 已基本解决），而是**退化问题（degradation）**：优化器找不到让新增层"至少不变差"的解。CIFAR 上 56 层 plain 网络比 20 层训练误差更高。

**残差形式化**：

$$y = F(x) + x$$

**梯度高速路**：

$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y}\cdot\left(1 + \frac{\partial F}{\partial x}\right)$$

### 直觉与要点

1. **学残差优于学恒等**：一串"卷积+BN+ReLU"非线性层逼近"输出=输入"出乎意料地难；残差连接给每层"什么都不做"的合法选项——学 F(x)≈0 远比学 F(x)=x 容易。
2. **梯度高速路**：+1 项让梯度不经任何权重矩阵直接回传，深层梯度不再连乘衰减——152 层甚至上千层可训。
3. **结构件**：基本块（两个 3×3，ResNet-18/34）vs bottleneck 块（1×1 降 → 3×3 → 1×1 升，ResNet-50/101/152）；stride=2 下采样处 shortcut 用 1×1 卷积对齐维度。
4. **战绩**：ILSVRC 2015 冠军，152 层，top-5 错误 3.57%，首次超过人类水平（约 5.1%）。

### 深入：退化问题的判别与机理（扩展）

**判别退化 vs 过拟合 vs 梯度消失**（面试三板斧）：

| 现象 | 训练误差 | 测试误差 | 诊断 |
|---|---|---|---|
| 过拟合 | 低 | 也高（gap 大） | 泛化失败 |
| 退化 | **升高** | 随之升高 | 优化失败 |
| 梯度消失 | 不降（长期高位） | 不降 | 信号传播失败（BN 后少见） |

退化的深层机理：多层复合的恒等映射 F(x)=x 要求权重矩阵近似正交、激活工作在近似线性区——**这不是优化的自然吸引子**；网络越深，到达该解的优化路径越窄。残差重参数化把"恒等"从需要学习的映射变成了默认路径（x 直接通过），学习只负责"增量"——优化问题的条件数大幅改善。这与第 5 周"重参数化改善优化"的主题一脉相承。

### 深入：ResNet 家族谱系（扩展）

- **ResNet v1.5**：下采样从第一个 1×1 挪到 3×3 上（stride 位置修正），官方与后续实现默认版本——读老代码注意版本差异；
- **Wide ResNet（WRN）**：加宽通道比加深更划算（k 倍宽度 ≈ 深度效果，并行友好）；
- **ResNeXt**：bottleneck 内引入分组卷积（基数 cardinality），Inception 多分支思想的"规整化"版本；
- **DenseNet**：每层连接**所有**前层（dense connectivity），特征复用极致、参数效率最高，代价是显存与算子碎片化；
- **预激活 ResNet（pre-activation）**：BN/ReLU 放卷积之前，梯度高速路更干净，是 Pre-Norm 思想在 CNN 的先声（对照第 6 周⑤）。

### 混合系统同构（原文）

残差连接 = 规则侧保底通道 / 影子模式 / 回滚机制的**恒等兜底**同构：新模型上线，影子模式先跑（只记录不决策），灰度发布逐步放量，一键回滚兜底——确保新版**至少不差于旧版**。残差块里的 +x 就是系统架构里的"旧链路始终在场"。

### 第 37 天自检参考答案（原文）

(a) 属于退化问题——判断依据是训练集准确率本身下降（过拟合应表现为训练高测试低；且现代网络有 BN，梯度消失已基本被解决，120 层 plain 网络配 BN 仍训练误差不降，病根是优化失败）；

(b) 恒等映射难学：对 plain 网络，新增的层若学不到有效特征，最优情况也应退化为恒等映射使网络至少不差于浅层，但一串非线性层逼近"输出=输入"出乎意料地难，新层反而把旧表征越传越差，于是加深即变差；

(c) 结构上：加入残差连接改为 ResNet 式 bottleneck 块（1×1 降 → 3×3 → 1×1 升），给每层"不改"的合法选项，梯度经 +1 高速路回传，120 层可训；发布流程上：影子模式 + 灰度发布 + 一键回滚兜底，确保新版至少不差于旧版，与残差的恒等兜底直觉一致。

## 第 7 周⑤（第 38 天）· CNN 工程清单：深度可分离卷积与轻量网络【推送原文】

### 核心概念

**一句话**：模型上生产环境要算两本账——**参数量**（决定内存/存储）和 **FLOPs**（决定延迟/功耗），深度可分离卷积用"先各通道自扫、再 1×1 混合"的拆法，把两本账同时砍掉约一个数量级。

**必要公式**（Cin/Cout 通道，特征图 H×W，3×3 卷积）：

| | 参数量 | FLOPs |
|---|---|---|
| 标准 3×3 卷积 | 9·Cin·Cout | 9·Cin·Cout·H·W |
| 深度可分离 | 9·Cin + Cin·Cout | (9·Cin + Cin·Cout)·H·W |
| 比值 | 1/9 + 1/Cout | ≈ **1/8 ~ 1/9** |

### 直觉类比（原文）

标准卷积像开会**全员两两单聊**（9·Cin·Cout 次沟通，随通道平方增长）；深度可分离改成两步：**组内开小会**（depthwise，各通道 3×3 自滤波，9·Cin 次）→ **派代表跨组对齐**（pointwise 1×1，Cin·Cout 次）。乘法变加法，降一个数量级而表达损失很小——因为"空间相关性"和"通道相关性"本来就可以分开建模。

### 关键要点

1. **两本账分开算，且 FLOPs 里藏着 H×W。** 浅层高分辨率处最烧钱；轻量网络第一刀降输入分辨率。FLOPs 只是代理指标：深度可分离**算术强度低、内存访问成本高**，实际延迟必须真机实测。
2. **MobileNet 三代演进 = "精度-效率"权衡史。** V1：深度可分离 + 宽度乘子 α + 分辨率乘子 ρ；V2：inverted residual + 线性瓶颈（ReLU 在低维破坏信息：先 1×1 升维 → depthwise → 1×1 降维，残差连在低维 bottleneck 之间，降维末层去非线性）；V3：NAS 搜索 + h-swish + SE。
3. **服务端 vs 移动端是两种物理。** 移动端约束 = 内存 + 功耗 + 单帧延迟三件套，选型看实际延迟而非参数量。
4. **事故案例（现象→根因→解法）**：端侧前置审核直接搬 ResNet-50，3 FPS 被迫回滚；根因是验收标准没纳入延迟预算；解法：MobileNetV3 + 输入 224→160 + INT8 量化，精度损失 <1 个点、帧率约 10 倍，"端侧粗筛 + 云端精审"各归其位。

### 深入：为什么 depthwise 的 FLOPs 降了、延迟却没同比降（扩展）

**算术强度（Arithmetic Intensity）= FLOPs / 内存访问量**。标准卷积每个权重参与 H·W 次乘加——权重从显存读一次、用 H·W 次；depthwise 每个 3×3 核只在自己通道的空间图上用，且 1×1 部分的访存/计算比高但 3×3 depthwise 部分访存密集——**整体 AI 下降，硬件从"算力受限"滑向"带宽受限"**。端侧 SoC/NPU 的带宽远比算力紧张，于是"FLOPs ÷ 8、延迟 ÷ 3"（自检题 b 的原型现象）。

**阿姆达尔定律**：系统加速比被最慢的非加速部分封顶——depthwise 替换后，BN、激活、首尾大通道层、预处理占比上升，成为新瓶颈。

**推论**：轻量网络设计的天花板不在 FLOPs 而在**内存访问模式**——ShuffleNet 的 channel shuffle、MobileNetV2 的线性瓶颈、GhostNet 的廉价冗余特征生成，本质上都在围绕访存做优化。选型评审带目标设备实测延迟，这一条规则比任何指标都重要。

### 深入：推理优化的三件套——量化、剪枝、蒸馏（扩展）

**量化（Quantization）**：权重/激活从 FP32 → INT8（或 INT4）。对称量化 x ≈ s·q（s 为缩放因子，逐通道或逐张量）。两阶段：

- **PTQ（训练后量化）**：校准数据跑一遍定 s——零成本，精度常掉 1 个点内；
- **QAT（量化感知训练）**：前向模拟量化误差反向传播适配——成本高，精度几乎无损。

经验：BN 折叠（conv+BN 合并）后量化；per-channel 权重 + per-tensor 激活是部署默认配方。

**剪枝（Pruning）**：结构化（砍通道/层——硬件真受益）与非结构化（砍权重到稀疏——需硬件支持稀疏算子才有收益）。大稀疏度 + 结构化才是部署语言。

**蒸馏（Knowledge Distillation）**：小模型（student）拟合大模型（teacher）的输出分布：

$$L = \alpha\, T^2 \cdot KL\big(\sigma(z_s/T),\ \sigma(z_t/T)\big) + (1-\alpha)\, CE(y, \sigma(z_s))$$

T>1 软化分布暴露类别间相似性（"猫"与"狐狸"比"猫"与"汽车"更像）——这是软标签信息量超过 one-hot 的原因。T² 补偿软分布梯度量级衰减。审核场景的级联系统（端侧小模型 + 云端大模型）天然是蒸馏的应用现场。

### 第 38 天自检题（原文）

某风控活体检测模型：Cin=Cout=256 的某一层，特征图 56×56，用标准 3×3 卷积。

(a) 计算该层的参数量与 FLOPs，换成深度可分离卷积后各是多少？

(b) 上线实测发现：换成深度可分离后 FLOPs 降了 8 倍，但端侧延迟只降了 3 倍——请给出至少两个可能原因；

(c) 如果预算只允许再砍一刀，你会优先砍输入分辨率还是通道数？为什么？

### 第 38 天自检参考答案（原文）

(a) 标准卷积：参数量 9·256·256 = 589,824，FLOPs = 589,824·56·56 ≈ 1.85G；深度可分离：参数量 9·256 + 256·256 = 2,304 + 65,536 = 67,840（约 1/8.7），FLOPs = 67,840·56·56 ≈ 212.8M（约 1/8.7）；

(b) 可能原因：①深度可分离算术强度低、内存访问成本高，FLOPs 降但数据搬运量没同比降，端侧受内存带宽瓶颈限制；②depthwise 算子在部分硬件/NPU 上优化差、利用率低；③网络中其他未替换部分（BN、激活、首尾层、数据预处理）占比上升成为新瓶颈（阿姆达尔定律）；

(c) 优先砍输入分辨率：FLOPs 与 H×W 成正比（平方级收益），且浅层高分辨率处本是烧钱大户；砍通道只线性降 FLOPs 且直接损失模型容量/精度；但需实测精度损失，活体检测对纹理细节敏感，分辨率降太多会伤精度，可配合宽度乘子微调。

## 第 7 周⑥（第 39 天 · 预告）· 周末串联复习：CNN 一周总串

> 本节为内容预告，正式推送后替换为原文。

1. **一周串联主线**：LeNet（卷积+池化奠基）→ AlexNet（ReLU+GPU+大数据）→ VGG（小卷积核堆叠、深度军备竞赛）→ Inception（多分支+1×1 降维）→ ResNet（残差解决退化、深度解禁）→ MobileNet（深度可分离、走向端侧）——每条演进都是"上一个瓶颈 → 新结构解法"的问题驱动逻辑。
2. **取舍框架表**：标准卷积（表达力强、贵）/ 1×1（通道混合、降维、便宜）/ 池化（降分辨率、平移不变性、丢信息）/ 残差（解决退化、恒等兜底）/ 深度可分离（省算力、端侧首选、内存访问成本高）——选型 = 在精度/延迟/内存三角中按部署约束取舍。
3. **推导**：从 y=F(x)+x 推梯度高速路 ∂L/∂x = ∂L/∂y·(1+∂F/∂x)，说明残差为何防梯度消失与退化。
4. **小练习**：①给混合系统审核场景（端侧前置+云端精审）选网络结构并说明理由；②给 plain 网络某段结构，改写成 bottleneck 残差块并标出 shortcut 维度对齐（stride=2 处 1×1）。
5. **混合系统串联**：规则侧保底通道 = 残差恒等兜底；端侧粗筛 + 云端精审 = 两阶段级联 = 计算预算分层。
6. **延伸阅读**：MobileNetV2/V3 论文、ShuffleNet（channel shuffle）、EfficientNet（复合缩放）。

### 深入：EfficientNet 复合缩放——"按什么比例同时放大三个维度"（扩展）

EfficientNet 系统化了轻量网络设计：网络规模由三个乘子控制——深度（层数 d）、宽度（通道 w）、分辨率（图像 r）。朴素放大只调一个；复合缩放按固定比例 φ 同时放大：**d = α^φ，w = β^φ，r = γ^φ，约束 α·β²·γ² ≈ 2**（平方项因为宽度/分辨率翻倍 FLOPs 近似平方增长）。网格搜索得 α≈1.2、β≈1.1、γ≈1.15。直觉：**更深抓更复杂特征、更宽抓更细粒度特征、更高分辨率服务小目标——三者要协同，单放大任何一个都会很快边际递减。** baseline 由 NAS（EfficientNet 的 Efficient 来源）搜出。

### 常见误区与面试考点（CNN 合集）

1. **1×1 卷积参数量** = Cin·Cout，与空间尺寸无关——别和 3×3 的 9·Cin·Cout 搞混；
2. **残差块的维度对齐**：x 与 F(x) 通道/尺寸不同时，shortcut 用 1×1 卷积 + stride 投影（不是简单相加会报错的细节，手写代码必考）；
3. **BN 之后为什么还需要残差**：BN 解决信号尺度、残差解决"优化器找不到恒等解"——两者作用层面不同，常共存；
4. **depthwise 后为什么必须接 pointwise**：depthwise 组间无信息流通，不混合通道 = 表达能力坍缩；
5. **FLOPs 的三个失真来源**：内存访问成本（depthwise）、算子碎片化（Inception）、激活/IO 占比（浅层）——所以部署评审只看实测延迟；
6. **面试速算模板**：参数量 = 卷积核元素 × Cin × Cout；FLOPs ≈ 参数量 × H_out × W_out（乘加算两次的约定下 ×2，说明约定即可）。

```python
import torch.nn as nn

class Bottleneck(nn.Module):                    # ResNet-50 风格 bottleneck
    def __init__(self, cin, cout, stride=1):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(cin, cout // 4, 1, bias=False), nn.BatchNorm2d(cout // 4), nn.ReLU(inplace=True),
            nn.Conv2d(cout // 4, cout // 4, 3, stride, 1, bias=False), nn.BatchNorm2d(cout // 4), nn.ReLU(inplace=True),
            nn.Conv2d(cout // 4, cout, 1, bias=False), nn.BatchNorm2d(cout),
        )
        self.shortcut = nn.Sequential()          # 恒等路径：尺寸/通道一致时为空
        if stride != 1 or cin != cout:
            self.shortcut = nn.Sequential(
                nn.Conv2d(cin, cout, 1, stride, bias=False), nn.BatchNorm2d(cout))
    def forward(self, x):
        return nn.ReLU(inplace=True)(self.conv(x) + self.shortcut(x))

class DWSeparable(nn.Module):                    # 深度可分离 3×3
    def __init__(self, cin, cout, stride=1):
        super().__init__()
        self.dw = nn.Conv2d(cin, cin, 3, stride, 1, groups=cin, bias=False)   # depthwise
        self.pw = nn.Conv2d(cin, cout, 1, bias=False)                          # pointwise
    def forward(self, x):
        return self.pw(self.dw(x))
```
