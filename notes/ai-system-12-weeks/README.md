# AI 系统学习笔记（12 周计划 · 第 1–39 天）

> 一份体系化的 AI/深度学习学习笔记。非科普路线：先立直觉，再上术语与公式，最后落到工程实践——既能当入门主线，也能当面试复习手册。

## 学习者画像与目标

适合这样的学习者：

- **想系统入门深度学习的人**：有编程基础即可（会 Python 最好），不要求事先修过机器学习课程；
- **用过模型但想搞清原理的人**：调过 API、跑过开源项目，想补上"为什么"——损失函数怎么推、反向传播怎么算、训练为什么会炸；
- **准备面试 / 复习基础的人**：每章附推导、代码与面试考点，可直接当复习提纲；
- **有工程经验想落地 AI 的人**：示例优先取材于"规则 + 模型"混合系统场景（审核、风控、推荐），讲解真实的事故案例与排查思路。

**共同目标**：不是"听说过"，而是能推导、能写代码、能排查问题。

## 教学约定

1. 先立直觉（类比 / "考试是什么"）再上术语，避免跳步；
2. 同一主题按 **直觉 → 形式化 → 数学 → 工程实践** 递进；
3. 工作日 10 分钟量：核心概念（一句话 + 必要公式）→ 直觉类比 → 关键要点 3–4 条 → 1 个自检问题；
4. 周末 20 分钟量：增加原理推导、小练习、本周串联复习、延伸阅读；
5. 结合真实工作场景的事故案例，按 **现象 → 根因 → 解法** 展开。

## 体例说明

每章按固定结构组织：

- **速览** — 原推送要点（核心概念 + 直觉类比 + 关键要点），10 分钟可读完；

- **常见误区与面试考点** — 高频易错点与面试问答；
- **延伸阅读** — 经典论文与书目。
